# Pendulum Studio 설치 안내 (0.2.0)

회전 도립 진자 키트로 강화학습을 배우는 Windows 앱입니다. **Python도 Node도 설치할 필요 없습니다.**
키트가 없어도 시뮬레이션으로 모든 활동을 해 볼 수 있습니다.

## 설치

1. `PendulumStudio-Setup-0.2.0.exe` 를 받아서 실행합니다.
   저장소의 [Releases](https://github.com/sjh030619-boop/furuta-pendulum-rl/releases) 에 있습니다.
   비공개 저장소라서 초대를 수락한 깃허브 계정으로 로그인해야 보입니다.
2. **파란 경고창이 뜹니다.** "Windows의 PC 보호" 창에서 **추가 정보**를 누르면 나오는
   **실행** 버튼을 누르세요. 코드 서명을 하지 않은 앱이라 뜨는 경고입니다.
3. 설치 위치를 물으면 그대로 두고 설치하면 됩니다. **관리자 권한은 필요 없습니다**
   (내 계정에만 설치됩니다).
4. 바탕화면과 시작 메뉴에 `Pendulum Studio` 아이콘이 생깁니다.

0.1.0이 설치된 PC에 덮어 설치하는 것은 시험하지 않았습니다. 문제가 생기면 0.1.0을 제거하고 다시 설치하세요.

## 화면

| 자리 | 있는 것 |
|---|---|
| 맨 위 | 작품 이름, 새로 만들기 / 불러오기 / 저장하기 / 도움말, `따라 하기`와 `자유롭게 만들기`, `키트 연결하기` |
| 메뉴 아래 | 활동 순서 1 → 2 → 3, 지금 할 일, `학습지에 예상을 적었어요` 표시 칸 |
| 왼쪽 | 진자 실행 화면, `시작하기`와 `정지하기`, `시뮬레이션`과 `실제 키트`, 결과와 기록 |
| 오른쪽 탭 | `살펴보기` / `블록` / `그래프` / `예시 규칙` |

## 해 보기

**1 살펴보기** — `미리 배운 에이전트 실행하기`를 누르면 시뮬레이션에서 미리 배운 AI가 진자를
세웁니다. 실행 화면을 끌면 돌려 볼 수 있고, 아래 네 칸에 상태·행동·보상·가치가 숫자로 나옵니다.

**2 점수 규칙 만들기** — `블록` 탭에서 점수 규칙을 정합니다.

- **따라 하기**: 블록 안의 고르는 칸(▼) 두 개를 없음 / 약하게 / 강하게로 바꿉니다.
  아홉 조합을 미리 학습해 두었고, 시뮬레이션에서는 아홉 조합 모두 진자를 세웁니다.
- **자유롭게 만들기**: 블록을 직접 쌓아 규칙을 만듭니다. 잘못 쌓은 규칙은 블록을 놓을 때 알려 줍니다.
  `예시 규칙` 탭에서 골라 시작해도 됩니다.

**3 가르치고 시험하기** — 예상을 학습지에 적고 `학습지에 예상을 적었어요`에 표시한 뒤
`시작하기`를 누릅니다. **표시하지 않으면 시작되지 않습니다.**

- 따라 하기는 미리 학습한 정책을 불러옵니다.
- 자유롭게 만들기는 미리 배운 정책에서 출발해 규칙에 맞게 다시 배웁니다
  (개발 PC에서 약 9초, 느린 노트북은 더 걸립니다).
- 배운 정책은 **안전 시험 40칸**을 봅니다. 37칸 이상이어야 통과입니다. 떨어지면 미리 배운 정책으로 시험합니다.
- 결과는 기록 표와 `그래프` 탭에 남습니다. 기록을 누르면 그 시도와 겹쳐 볼 수 있습니다.
- **작품은 자동으로 저장되지 않습니다.** 앱을 닫기 전에 `저장하기`로 파일을 만드세요.
  블록은 저장되고, 기록 표와 배운 정책은 저장되지 않습니다.

## 실제 키트 연결

**모터가 움직입니다. 담당자가 키트 옆에 있을 때만 하세요.** 팔이 도는 범위를 비우고 손을 떼야 합니다.

앱만 설치해서는 연결되지 않습니다. 키트의 라즈베리파이에서 키트 프로그램(`kit_server.py`)이 돌고 있고,
노트북에 그 키트의 COM 포트가 보여야 합니다. 준비 방법은 `app/kit/README.md` 에 있습니다.

1. `키트 연결하기` → 목록에서 키트를 고르고 `연결`.
2. `키트 맞추기` 창이 뜹니다. 창이 뜨는 것만으로는 모터가 움직이지 않습니다.
   `맞추기 시작`을 누르면 **약 40초 동안 모터가 움직입니다.** 건너뛰려면 `나중에`를 누릅니다.
3. `키트 상태` 탭의 `키트 점검`은 모터를 움직이지 않고 모터와 진자 센서만 읽습니다.
4. 안전 시험을 통과하고 시뮬레이션에서 진자를 세운 정책만 `실제 키트`로 시험할 수 있습니다.
5. 실행할 때마다 키트가 먼저 팔을 돌려 받침 수평을 잽니다. 받침이 5° 넘게 기울면 정책을 실행하지 않습니다.
6. 멈추려면 `정지하기`를 누릅니다. 너무 빨리 돌 때, 진자가 계속 돌 때, 연결이 2초 끊겼을 때는
   키트가 스스로 멈춥니다. 다만 키트 맞추기에서 팔 마찰을 재는 동안(약 7초)은 이 정지 명령이
   그 측정이 끝난 뒤에 처리됩니다.

### 아직 확인하지 못한 것 (2026-11-25)

- **USB 케이블로 직접 잇는 것.** 실제 키트 실행과 정지 단추는 SSH 연결로 확인했습니다.
- **수평 측정과 키트 맞추기의 실기 시험.** 가짜 키트로만 확인했습니다.
- **이 설치 파일(0.2.0)로 실제 키트를 연결하는 것.**
- 안전 시험을 통과한 정책도 실제 키트에서 실패할 수 있습니다.
  2026-11-24 실기에서 고친 정책 5개 중 1개가 직립을 지나쳐 계속 돌았습니다.

## 안 되는 것

- Windows용만 있습니다. Mac용 설치 파일은 만들지 않았습니다.
- 화면 글꼴은 인터넷에서 받습니다. 인터넷이 없으면 기본 글꼴로 나옵니다.
- 자동 업데이트는 없습니다. 새 버전은 다시 받아 설치하세요.

## 지우기

설정 → 앱 → 설치된 앱 → Pendulum Studio → 제거. `저장하기`로 만든 파일은 남습니다.
