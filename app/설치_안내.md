# Pendulum Studio 설치 안내

회전 도립 진자 키트로 강화학습을 배우는 앱입니다. **Python도 Node도 설치할 필요 없습니다.**

## 설치

1. `PendulumStudio-Setup-0.2.0.exe` 를 받아서 실행합니다.
2. **파란 경고창이 뜹니다.** "Windows의 PC 보호 — Microsoft Defender SmartScreen이
   인식할 수 없는 앱의 시작을 차단했습니다."
   → **추가 정보**를 누르면 나오는 **실행** 버튼을 누르세요.

   코드 서명 인증서(연 30만 원쯤)를 사지 않은 앱은 전부 이 경고가 뜹니다. 바이러스라서가
   아니라 "만든 사람이 누군지 Microsoft가 보증해 주지 않았다"는 뜻입니다.
3. 설치 위치를 물으면 그대로 두고 설치하면 됩니다. **관리자 권한은 필요 없습니다**
   (내 계정에만 설치됩니다).
4. 바탕화면과 시작 메뉴에 `Pendulum Studio` 아이콘이 생깁니다.

## 무엇을 보면 되나

화면 위쪽 탭이 활동 순서입니다. 학습지와 같은 3단계입니다.

**1 살펴보기** — `실행하기`를 누르면 미리 배운 AI가 진자를 세웁니다(0.4초쯤 걸립니다).
화면을 끌면 돌려 볼 수 있습니다. 아래 네 칸이 강화학습의 용어(상태·행동·보상·가치)가
실제로 어떤 숫자인지 보여 줍니다.

**2 규칙 만들기** — `부드럽게`와 `힘 아끼기`를 없음/약하게/강하게로 바꿔 봅니다.
**규칙을 바꾸면 움직임이 실제로 달라집니다.** 아홉 조합을 전부 따로 학습시켜 넣어 두었습니다.

> `빠르기 강하게` + `힘 아끼기` 조합 두 개는 **일부러 못 세웁니다.** 버그가 아닙니다 —
> 진자 속도를 세게 깎으면 스윙업에 필요한 에너지를 넣을 수 없습니다. 학습지 4쪽이 묻는
> 것이 바로 이 현상입니다.

`심화: 블록으로 만들기`를 누르면 엔트리처럼 블록을 쌓아 점수 규칙을 직접 만들 수 있습니다.
새 규칙을 만들면 가장 비슷한 정책에서 출발해 화면 안에서 몇 초 동안 다시 학습합니다.

**3 가르치고 시험하기** — `가르치기` → `시뮬레이션`. 보상 곡선과 진자 각도 그래프가 그려지고
시험 기록에 결과가 쌓입니다.

## 안 되는 것

- **실제 키트 연결**은 비활성입니다. 하드웨어 구성이 아직 정해지지 않아서,
  앱 쪽 연결 부분(`PROTOCOL.md`의 줄 단위 프로토콜)만 만들어 둔 상태입니다.
- 메뉴바의 `장치`·`연결`은 눌러 볼 수는 있지만 붙을 장치가 없습니다.

## 지우기

설정 → 앱 → 설치된 앱 → Pendulum Studio → 제거.
